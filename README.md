# zukei-drafter（図形PNGジェネレーター）

公開URL: https://edi-tool.github.io/zukei-drafter/

教材・書籍・プリントで使う 2D / 3D 図形を、**数値入力から数学的に生成**し、
プレビューして高解像度PNG（またはSVG）として保存できる静的Webアプリです。

自由配置・編集を行う作図ツールではなく、「数値を指定 → 図形を生成 →
プレビュー → 画像として保存」という図形ジェネレーターです。

## 使い方

ビルド不要です。リポジトリを clone (または GitHub Pages で公開) して
`index.html` をブラウザで開くだけで動作します。

```
git clone <このリポジトリ>
cd zukei-drafter
python3 -m http.server 8000   # 任意の静的サーバーでOK
# ブラウザで http://localhost:8000 を開く
```

1. 上部で「2次元」「3次元」を切り替えます。
2. 左のパネルで図形の種類・寸法・角度などを入力します。値を変更すると
   即座に中央のプレビューへ反映されます。
3. 2D「三角形」「一般多角形」では、数学的に成立しない入力（三角不等式を
   満たさない、多角形が閉じないなど）はエラーメッセージで通知されます。
4. 線色・線幅・塗り、3Dの隠線表示方法などを調整できます。
5. 「PNGを保存」で背景（透明/白）・解像度（1x/2x/4x、600px基準）を選んで
   高解像度PNGを保存できます。「SVGを保存」でSVGファイルとしても保存
   できます。

## 対応図形

* **2D**: 正多角形（頂点数3〜20）、三角形（SSS/SAS/ASA）、一般多角形
  （各辺の長さと方向角を指定、閉合チェック付き）
* **3D**: 立方体・直方体・三角柱・四角柱・三角錐・四角錐・円柱・円錐
* **投影法**: 等角投影・カバリエ投影・キャビネット投影・任意斜投影
  （斜投影は奥行き角度・奥行き倍率を指定可能）
* **隠線**: 多面体は面の向きから可視/不可視エッジを近似判定し、破線表示
  または非表示を選択可能

## 設計概要

* HTML / CSS / Vanilla JavaScript のみ。フレームワーク・ビルドステップなし。
* SVGを描画の正本とし、PNG保存はSVGをCanvasに描画して
  `canvas.toBlob()` で行う（ブラウザ標準APIのみ）。
* 幾何計算（`js/geometry2d.js`, `js/geometry3d.js`, `js/projections.js`,
  `js/ellipse.js`, `js/hidden-line.js`）はすべて **DOMに依存しない純粋関数**
  として実装し、SVG描画（`js/render-svg.js`）・シーン構築
  （`js/scene-builder.js`）・PNG/SVG出力（`js/export-png.js`）・UI配線
  （`js/app.js`）と責務を分離しています。
* 円柱・円錐は多角形近似ではなく、「線形写像による円の像は厳密に楕円に
  なる」性質を利用して楕円のパラメータ（中心・長短軸・回転角）を解析的に
  求め、SVGの `<ellipse>` として描画しています。側面の輪郭線・円錐の
  母線も接線計算により求めています。

詳細な設計判断・曖昧点への対応は [REQUIREMENTS.md](./REQUIREMENTS.md) を、
モジュール構成・データフローは [ARCHITECTURE.md](./ARCHITECTURE.md) を
参照してください。

## 依存ライブラリについて

**本番動作に外部ライブラリは一切使用していません**（依存ゼロ）。
幾何計算・投影計算・SVG→PNG変換はいずれも自前実装、または
`Image` / `Canvas` / `Blob` などのブラウザ標準APIのみで実現しています。
（採用しなかった理由・調査内容は REQUIREMENTS.md の「対応する既存OSS調査」
節を参照）

開発時のテストのみ、Node.js 標準の `node:test` / `node:assert` を使用して
います（追加npmパッケージも不要です）。

## テスト

```
npm test
```

`tests/*.test.mjs` に、正多角形・三角形（SSS/SAS/ASA、不成立入力の検出）・
一般多角形の閉合判定・等角投影/カバリエ投影/キャビネット投影・円柱/円錐の
楕円投影・多面体の隠線判定・SVGシーン生成の自動テストがあります
（Node.js 18+の `node --test` で実行、追加依存なし）。

ブラウザでの動作確認（UI操作・PNG/SVGダウンロード・コンソールエラー
チェック）は開発時に Playwright で手動検証しました
（本番動作には不要・必須にはしていません）。

## 未実装・既知の制限事項（v1）

* 寸法線・角度ラベル・頂点名の自動配置はv1では未実装です
  （ジオメトリとレンダラーを分離してあるため、将来追加しやすい構造には
  なっています）。
* 多面体の隠線判定は、面の向きと近似的な視線方向からの簡易判定であり、
  一般の凹多面体・複雑な自己遮蔽に対する完全な可視性アルゴリズムでは
  ありません。対応するプリミティブ（立方体・直方体・角柱・角錐）では
  正しく見えることを確認しています。
* 円柱・円錐の側面輪郭線は、投影が線形写像であることを利用した近似
  （水平方向の極値点を接点とする）で求めています。対応する投影法
  （等角・カバリエ・キャビネット・任意斜投影）では視覚的に正しい
  結果になることを確認しています。
